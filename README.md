# NumNinja – Educational Math Game

## Overview

NumNinja is an Android educational game developed using **Kotlin** in **Android Studio**. The app is designed to help users improve their basic mathematics skills through interactive gameplay. It was developed as part of the **CP5307 Mobile Application Development** course.

## Features

* Three difficulty levels (Easy, Medium, Hard)
* Image-based math questions
* 30-second game timer
* Leaderboard with player rankings
* Save scores using Room Database
* Daily practice reminder using WorkManager
* Notification ON/OFF option in Settings
* Runtime notification permission (Android 13+)
* Screen rotation support
* Delete confirmation before clearing the leaderboard

## Technologies Used

* Kotlin
* Android Studio
* MVVM Architecture
* Room Database
* WorkManager
* ViewModel
* LiveData
* RecyclerView
* Material Design Components

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/pbibekk66/EduApp.git
   ```
2. Open the project in Android Studio.
3. Sync the Gradle files.
4. Run the app on an emulator or Android device.
